# Express Starter Template

A starter template for Express + PostgreSQL + Passport projects. Clone this repo instead of setting up from scratch every time.

---

## Starting a New Project

### 1. Clone the repo

```bash
git clone https://github.com/JosephSamuel3/express-starter-template.git project-name
```

Replace `project-name` with the name of your new project.

### 2. Move into the project folder

```bash
cd project-name
```

### 3. Remove the template's git history

```bash
rm -rf .git
```

Then initialize a fresh git repo for your new project:

```bash
git init
```

### 4. Install dependencies If needed (most needed to run the app already installed )

```bash
npm install
```

### 5. Set up your environment variables

```bash
cp .env.example .env
```

Open `.env` and fill in your database credentials and session secret:

```env
PORT=3000

DB_HOST=localhost
DB_USER=postgres
DB_PASSWORD=your-password
DB_NAME=your-database
DB_PORT=5432

SESSION_SECRET=your-secret-key
```

### 6. Start the development server

```bash
npm run dev
```

This runs `src/app.ts` directly through `ts-node`, restarting on changes via `nodemon`. App will be running at `http://localhost:3000`.

### 7. Build for production

```bash
npm run build
npm start
```

`npm run build` compiles `src/` to `dist/` with `tsc`, and `npm start` runs the compiled output.

## What's Included

| Path | Purpose |
|---|---|
| `src/app.ts` | Express app entry point |
| `src/db/pool.ts` | PostgreSQL connection pool |
| `src/config/passport.ts` | Passport local strategy |
| `src/middleware/auth.ts` | `isAuthenticated` / `isGuest` middleware |
| `src/routes/index.ts` | Base routes (home, login, logout) |
| `src/controllers/` | Route handler functions |
| `src/types/express.d.ts` | `Express.User` type augmentation for Passport |
| `views/` | EJS templates with partials |
| `public/` | Static CSS, JS, and images |
| `models/` | Database model files |
| `dist/` | Compiled JS output (gitignored, generated by `npm run build`) |
| `CHECKLIST.md` | Project setup checklist |

## Stack

- [TypeScript](https://www.typescriptlang.org/)
- [Express](https://expressjs.com/)
- [EJS](https://ejs.co/)
- [PostgreSQL](https://www.postgresql.org/) via [node-postgres](https://node-postgres.com/)
- [Passport](https://www.passportjs.org/) (local strategy)
- [bcryptjs](https://github.com/dcodeIO/bcrypt.js)
- [express-session](https://github.com/expressjs/session)
- [express-validator](https://express-validator.github.io/)
- [dotenv](https://github.com/motdotla/dotenv)
- [ts-node](https://typestrong.org/ts-node/) + [nodemon](https://nodemon.io/) (dev)
